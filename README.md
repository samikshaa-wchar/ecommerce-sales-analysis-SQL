
# 🛒 E-commerce Sales Analysis using SQL

## 📌 Project Overview

This project focuses on analyzing e-commerce data using SQL to extract meaningful business insights. The goal is to understand product performance, category-wise distribution, customer behavior, and sales trends through structured SQL queries.

The project demonstrates practical SQL skills, including data retrieval, aggregation, filtering, grouping, sorting, and business-oriented data analysis.

## 🎯 Project Objectives

* Analyze e-commerce product and customer data.
* Identify top-performing products and categories.
* Calculate key business metrics using SQL.
* Explore customer distribution and purchasing patterns.
* Answer business questions using data-driven queries.
* Practice SQL skills through a real-world business scenario.

## 🛠️ Tools & Technologies

* **IDE:** MySQL Workbench

## ❓ Business Questions

This project explores business questions such as:

1. How many products are available in the database?
2. How many products belong to each category?
3. Which categories contain the most products?
4. What is the average price of products in each category?
5. Which are the top 5 products based on the selected business metric?
6. Which cities have the most customers?
7. Which brands have the highest product counts?
8. Which categories have an average product price above a specified threshold?

These questions help demonstrate how SQL can support business analysis and decision-making.
